Under the hood

Three messages. Then no one else can listen.

The XX pattern authenticates both sides and derives keys that live and die with the session. Lose them and the past stays sealed.

01
-> e

Client opens

The client sends a one-time ephemeral key to start the exchange.

02
<- e, ee, s, es

Server answers

The server mixes shared secrets and returns its encrypted identity.

03
-> s, se

Channel sealed

The client proves itself, both sides derive transport keys, and chat begins.
